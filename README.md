## 🌟 مميزات النظام

- **🔍 ماسح باركود ذكي وفوري:** التعرف على الأدوية وتاريخ الصلاحية والجرعة تلقائياً عبر الكاميرا بدون كتابة يدوية.
- **⏱️ تتبع دقيق لتواريخ الصلاحية:** تصنيف الأدوية حسب الحالة (صالح للاستخدام، وشيك الانتهاء، تالف/منتهي).
- **📉 تقارير الخسائر والمخاطر:** تتبع الهدر المالي ومحاضر الإتلاف الرسمية لحماية الصيدلية من المساءلة القانونية.
- **👥 نظام صلاحيات متقدم (RBAC):** حسابات منفصلة لمدير الصيدلية (Admin) وموظفي الصيدلية (Staff).
- **🎨 هوية بصرية متميزة:** شاشة افتتاحية (Splash Screen) راقية بخلفية أخضر بترولي تركوازي داكن (Teal) مع شعار ثلاثي الأبعاد دقيق.
- **☁️ مزامنة سحابية وقاعدة بيانات موثقة:** حفظ حسابات الصيادلة ورخص الممارسة وبيانات الأدوية على Firestore.
- **📱 تطبيق ويب تقدمي (PWA):** يعمل بسلاسة على الموبايل والتابلت والكمبيوتر.

## 🚀 تشغيل المشروع محلياً

```bash
# 1. تثبيت الحزم البرمجية
npm install

# 2. تشغيل بيئة التطوير
npm run dev

# 3. بناء المشروع للإنتاج
npm run build
```
